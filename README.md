# 12

i build self-hosted infrastructure that replaces cloud dependencies with local-first tools. memos, vikunja, radicale and ntfy run on a single vCPU, stitched together with small rust daemons and MCP servers so my AI agents can use them too.

when i'm not fighting nginx configs, i'm ricing windows or making games in godot.

## rust · self-hosted

| project | what it does |
|---|---|
| [memos-mcp-server](https://github.com/0124212/memos-mcp-server) | MCP server for Memos: 20 tools + prompts/resources, Streamable HTTP + stdio (rmcp) |
| [memogram-rs](https://github.com/0124212/memogram-rs) | Telegram → Memos bridge, 40+ commands (`/search` `/daily` `/arxiv` `/translate`), single binary |
| [memotag-rs](https://github.com/0124212/memotag-rs) | auto-tags Memos notes by regex: media, code, tasks, quotes, bookmarks |
| [vikunja-reminders](https://github.com/0124212/vikunja-reminders) | low-RAM reminder agent that routes due dates to Discord / Slack / ntfy via `rules.json` |
| [openorchestra](https://github.com/0124212/openorchestra) | orchestrator for a VPN worker fleet (WIP) |
